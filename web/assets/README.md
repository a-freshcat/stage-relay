# 图标来源

- `relay.svg`：根据本项目确认的界面草图实现的 Stage Relay 标识。
- `relay.ico`：将本项目标识绘制为 Windows 程序图标。
- `codex.ico`：本机已安装的 OpenAI 桌面应用资源 `chatgpt-app-light.ico`，用于标识该工作应用。
- `dsh.svg`：[DeepSeek Harness 官方 favicon](https://github.com/deepseek-ai/deepseek-harness/blob/master/website/public/favicon.svg)。
- `antigravity.svg`：[Google Antigravity 官方品牌图标](https://antigravity.google/press)。

应用图标用于在本地原型中标识协作成员所属应用，不表示所属厂商为本项目背书。
